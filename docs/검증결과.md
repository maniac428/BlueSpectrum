## v1.7 그래프를 그릴 GPU 선택

2026-09-14 설정에 **그래프를 그릴 GPU** 목록을 추가했습니다. 자동 선택 또는 인식한 하드웨어 GPU의 모델을 선택하고 적용하면 실행 중 그래프 장치를 전환합니다. 선택값은 설정에 저장하며, 기본값은 그래프 장치 초기화 시 현재 창의 모니터에 연결된 GPU를 우선하는 자동 선택입니다. 감상 모드로 시작, 올블랙 배경, 창 위치·크기 복원과 다섯 위치 버튼은 유지합니다.

### 원본 대조 근거

- [제조사 서비스 매뉴얼 Page 7](https://www.manualslib.com/manual/4098885/Technics-Sh-E70.html?page=7): IC51/52의 -12~+12dB, 2dB 간격 13개 막대 레벨 출력.
- [제조사 서비스 매뉴얼 Page 16](https://www.manualslib.com/manual/4098885/Technics-Sh-E70.html?page=16): 7개 주파수와 FULL RANGE, 눈금, 상태 표기 영역의 FL 표시관 도면.

표시관 도면의 a~m이 막대의 13개 이중선쌍에 대응합니다. a~z의 나머지 세그먼트에는 눈금과 상태 문자가 포함되므로, 전체 26개를 26개의 독립 막대 단계로 해석하지 않았습니다. 픽셀 단위의 완전 일치, 실제 FL 발광색·잔광·아날로그 교정값의 일치까지 확인한 것은 아닙니다. 기존 v1.0의 20단·-60~0 표시는 원본 재현에 부족했으며 v1.1에서 변경했습니다.
