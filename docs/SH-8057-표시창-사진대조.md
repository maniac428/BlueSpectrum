사용자가 추가 제공한 고해상도 근접 사진(막대 점등·미점등), 전체 기기 사진과 서로 다른 판매자가 촬영한 [Reverb 실물 사진](https://reverb.com/item/41999248-technics-sh-8057-stereo-graphic-eq-programmable-spectrum-readout-14-bands-ex-sound-japan), [eBay 점등 사진](https://i.ebayimg.com/images/g/i4oAAeSwQOlp3GeG/s-l1200.webp), [eBay 소등 사진](https://i.ebayimg.com/images/g/dywAAeSwAVppu83l/s-l1200.webp)을 대조했다. Reverb 목록의 여러 컷은 같은 기기이므로 독립 사례 하나로 취급했다. 사용자 제공 영상은 움직이는 막대의 존재를 확인하는 보조 자료로만 사용했다.

|---|---|
| 좌우 표시창이 분리되고 각각 7개 주파수 칸과 `full range` 칸이 있음 | 채널당 8열, 좌우 독립 표시 |
| 켜진 막대는 넓은 블록이 아니라 촘촘한 가로 발광선이 세로로 쌓임 | 사진에서 세로 픽셀 밝기 주기를 확인해 약 26개의 얇은 선으로 재구성 |

추가 제공된 고해상도 점등 사진의 2.5kHz 막대 중심에서는 밝은 선의 세로 간격이 대략 7픽셀이며, 표시창 전체 높이에 약 26개가 들어간다. 사진의 압축·광학 번짐 때문에 이는 시각적 추정이고 제조사 세그먼트 수의 확정값은 아니다. 점등 사진마다 노출, 화이트밸런스, 화면 모드, 입력 소리가 달라 색과 각 막대 높이가 크게 달라진다. 따라서 색과 밝기는 여러 사진의 공통 인상을 따른 시각적 근사치다. 정지 사진만으로 원기기의 정확한 응답 시간, 색좌표 또는 휘도를 계측할 수 없다. 판매 설명의 `LED` 표기는 원기기 표시 방식에 대한 검증 자료로 쓰지 않았다.
