# SH-8057 표시창 사진 대조

사용자가 추가 제공한 고해상도 근접 사진(막대 점등·미점등), 전체 기기 사진과 서로 다른 판매자가 촬영한 [Reverb 실물 사진](https://reverb.com/item/41999248-technics-sh-8057-stereo-graphic-eq-programmable-spectrum-readout-14-bands-ex-sound-japan), [eBay 점등 사진](https://i.ebayimg.com/images/g/i4oAAeSwQOlp3GeG/s-l1200.webp), [eBay 소등 사진](https://i.ebayimg.com/images/g/dywAAeSwAVppu83l/s-l1200.webp)을 대조했다. Reverb 목록의 여러 컷은 같은 기기이므로 독립 사례 하나로 취급했다. 사용자 제공 영상은 움직이는 막대의 존재를 확인하는 보조 자료로만 사용했다.

| 반복 확인된 형태 | 프로그램에 반영한 내용 |
|---|---|
| 좌우 표시창이 분리되고 각각 7개 주파수 칸과 `full range` 칸이 있음 | 채널당 8열, 좌우 독립 표시 |
| 켜진 막대는 넓은 블록이 아니라 촘촘한 가로 발광선이 세로로 쌓임 | 사진에서 세로 픽셀 밝기 주기를 확인해 약 26개의 얇은 선으로 재구성 |
| 막대 사이와 양끝에 밝은 기준점이 별도의 세로 열을 이루며 각 열에 다섯 점이 있음 | 막대 8열과 독립된 기준점 9열 × 5점. 소리가 없을 때도 표시 |
| 각 표시창 위에 `left channel`·`right channel`, 아래에 주파수 및 `equalizer`·`spectrum` 표기 | 해당 문구와 좌우 눈금 배치 수정 |
| 왼쪽 EQ 눈금은 ±12, 오른쪽 스펙트럼 눈금은 0~36 | 서로 다른 두 눈금을 유지 |
| 일반 막대 폭은 인접 막대 중심 간격의 약 40%, `full range` 막대는 일반 막대의 약 두 배 | 막대 폭·마지막 막대 중심·기준점 위치를 사진 비율에 맞게 조정 |

사용자 제공 좌측 고해상도 점등 사진에서 일반 막대 중심 간격은 약 100픽셀, 막대 본체 폭은 약 40픽셀이었다. `full range` 본체는 약 80픽셀이고 16kHz 막대보다 약 115픽셀 떨어져 있었다. 촬영 각도와 발광 번짐이 있어 치수는 근사치다. 프로그램은 이에 맞춰 일반 막대 폭/중심 간격을 약 0.41, 마지막 막대 폭/일반 막대 폭을 2.0으로 조정했다. 아래 조절 바와 중앙 빈 구간은 사용자 요청에 따라 표시하지 않는다.

기준점은 점의 왼쪽 끝이 아닌 **점의 중심**을 눈금 위치로 삼는다. 각 막대 중심은 양옆 기준점 중심의 정확한 중간에 놓고, 양끝 기준점도 같은 규칙으로 배치한다.

[사용자가 제공한 SH-8057 영상](https://www.instagram.com/reel/DcFNXSrOC9i/)과 [별도 SH-8057 시연 영상](https://www.youtube.com/watch?v=lifi-bVpL5k)에서 막대가 음원에 따라 아래에서 위로 반응하는 모습은 확인했다. 두 영상 모두 장치와 오디오 신호를 동시에 계측한 자료가 아니고 촬영 거리·영상 프레임·표시 모드의 차이가 있어, 상승·하강 시간을 제조사 수치처럼 확정할 수 없다. 프로그램은 빠른 상승과 느린 하강을 기본 움직임으로 두고 설정에서 조정할 수 있게 한다.

추가 제공된 고해상도 점등 사진의 2.5kHz 막대 중심에서는 밝은 선의 세로 간격이 대략 7픽셀이며, 표시창 전체 높이에 약 26개가 들어간다. 사진의 압축·광학 번짐 때문에 이는 시각적 추정이고 제조사 세그먼트 수의 확정값은 아니다. 점등 사진마다 노출, 화이트밸런스, 화면 모드, 입력 소리가 달라 색과 각 막대 높이가 크게 달라진다. 따라서 색과 밝기는 여러 사진의 공통 인상을 따른 시각적 근사치다. 정지 사진만으로 원기기의 정확한 응답 시간, 색좌표 또는 휘도를 계측할 수 없다. 판매 설명의 `LED` 표기는 원기기 표시 방식에 대한 검증 자료로 쓰지 않았다.
